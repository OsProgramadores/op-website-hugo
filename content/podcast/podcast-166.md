In this episode of the OsProgramadores Podcast, Marcelo talks with Felicitas Pojtinger, an experienced software developer deeply involved in the open-source ecosystem and currently works in Research & Development at Loophole Labs, exploring technologies around checkpoint/restore, live migration, virtualization, and networking.

Our conversation explores her career, open source, infrastructure engineering, building software that lasts, developer communities, and the fascinating technical challenges behind modern computing infrastructure.

👩‍💻 About the Guest

Felicitas Pojtinger is a software developer passionate about building infrastructure designed to last.

Her work spans several important areas of modern computing:

🐧 Linux
☸️ Kubernetes
🖥️ Virtualization
🌐 Networking
🕸️ WebAssembly
💻 GNOME
🔓 Open Source

She is an active contributor to the open-source ecosystem and can be found across platforms including GitHub and Codeberg under the username pojntfx.

Currently, Felicitas works in R&D at Loophole Labs, focusing on challenging areas such as:

🔄 Checkpoint and Restore
🚀 Live Migration
🖥️ Virtualization
🌐 Networking

She is also the creator and maintainer of several interesting open-source projects.

🛠️ Open Source Projects

Some of Felicitas' notable projects include:

🌐 weron

An overlay network based on WebRTC.

💾 go-nbd

A pure Go implementation of the Network Block Device (NBD) protocol.

🖥️ bofied

A modern network boot server designed to simplify network boot infrastructure.

These projects demonstrate a recurring theme in Felicitas' work: building practical infrastructure tools while exploring challenging problems in networking, virtualization, distributed systems, and open-source software.

🏗️ Building Infrastructure That Lasts

One of the fascinating themes behind Felicitas' work is the idea of building infrastructure that stands the test of time.

Infrastructure software often operates behind the scenes, but it powers nearly everything we interact with.

From containers and Kubernetes to virtualization platforms and distributed networks, reliable infrastructure requires careful engineering and a deep understanding of systems.

The open-source ecosystem plays a critical role in this process, allowing developers from around the world to collaborate, experiment, review ideas, and build tools that can become foundational technologies.

🔓 Open Source and Community

Open source is much more than publishing code.

It is about:

🤝 Collaboration

📚 Sharing knowledge

🔍 Transparency

🌎 Global communities

🧪 Experimentation

🚀 Innovation

Felicitas' work across multiple open-source communities provides an interesting perspective on how developers can contribute to the broader technology ecosystem while also developing their own careers and technical expertise.
